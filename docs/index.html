    Why Kilobyte

    Designed to feel like a missing WordPress Core feature.

    Kilobyte adds one screen under Media in your WordPress admin. It shows no ads, asks for no account, and never changes your original files.

    Works on activation

    There is no account to create and no API key to paste. Images are compressed in your browser, or by the image editor your WordPress site already has.

    No ads or upsells

    Kilobyte shows no upgrade banners. Every setting you see is included and free.

    Looks like WordPress

    The Kilobyte screen is built from WordPress’s own interface components, so it looks and behaves like the rest of your admin.

    Safe by default

    Browsers that cannot show WebP or AVIF get your original image. If you restore an image, the old copies stay available for at least 24 hours, so cached pages keep working.

    For developers and AI assistants

    Run Kilobyte from code, the command line, or an AI assistant.

    Kilobyte follows the WordPress VIP Go coding standards, loads no Composer packages in production, and is covered by more than 510 integration tests that run against real WordPress.

    WordPress Abilities API
    On WordPress 6.9 and newer, Kilobyte registers seven abilities that AI assistants and MCP adapters can call. Each one has a JSON schema and checks the user’s permission for the image.
    WP-CLI
    Check savings, optimize in batches, restore images, and clear old backup records from your terminal or deploy scripts.
    PHP hooks
    Lock settings in code across client sites, skip chosen images, and purge your page cache when a copy is created or restored.
    WordPress 6.9 and newer 
    // Available in PHP, over REST at /wp-json/wp-abilities/v1/,
// and through MCP adapters.

$stats = wp_get_ability( 'kilobyte/get-stats' )->execute();

$queue = wp_get_ability( 'kilobyte/get-queue' )->execute(
	array(
		'mode'     => 'optimize',
		'per_page' => 25,
	)
);

$result = wp_get_ability( 'kilobyte/optimize-image' )->execute(
	array( 'attachment_id' => 42 )
);

// The other four abilities:
// kilobyte/get-settings      kilobyte/update-settings
// kilobyte/restore-image     kilobyte/regenerate-thumbnails
    wp kilobyte 
    # See how much your Media Library has saved.
wp kilobyte stats
wp kilobyte stats --reconcile

# Optimize the next 100 images that still need it.
wp kilobyte optimize --limit=100

# Restore one image, or every image.
wp kilobyte restore 42
wp kilobyte restore --all

# Clear old backup records after you archive them.
wp kilobyte purge-backups
    functions.php 
    // Lock settings in code across client sites.
add_filter(
	'kilobyte_io_settings',
	static function ( array $settings ): array {
		$settings['format']  = 'webp';
		$settings['quality'] = 80;
		return $settings;
	}
);

// Skip chosen images.
add_filter(
	'kilobyte_io_should_optimize',
	static function ( bool $run, int $id ): bool {
		return $run && ! get_post_meta( $id, '_keep_original', true );
	},
	10,
	2
);

// Purge your page cache when a copy is created or restored.
add_action(
	'kilobyte_io_variant_changed',
	static function ( int $attachment_id ): void {
		// Call your host or cache plugin here.
	}
);

    Questions

    What people ask before they install.

    Is Kilobyte really free and unlimited?

    Yes. Kilobyte is free, has no limits, and needs no account. Images are compressed in your own browser, or by your WordPress site’s image editor, so there are no compression servers for anyone to pay for.

    Will it overwrite my original photos or break cached pages?

    No. Kilobyte keeps your original files and their links, and saves each smaller WebP or AVIF image as a separate copy. Browsers that cannot show the copy get the original. If you restore an image, the old copies stay available for at least 24 hours, so cached pages keep working. If your page cache keeps pages for longer than a day, clear the affected pages after you restore.

    What happens to animated GIFs, APNGs, and animated WebPs?

    Kilobyte checks each image before it compresses anything. Animated GIFs, APNGs, and animated WebPs are left exactly as they are, so the animation keeps working. Still GIFs can get smaller WebP or AVIF copies.

    What does my site need to run Kilobyte?

    WordPress 6.6 or newer and PHP 7.4 or newer. Your host also needs GD or Imagick, the standard WordPress image editors, which almost every host has. Kilobyte does not need exec() or any extra server software.

    Can an AI assistant use Kilobyte?

    Yes. On WordPress 6.9 and newer, Kilobyte registers seven abilities through the WordPress Abilities API. An AI assistant or MCP adapter connected to your site can read savings, list the images still waiting, optimize or restore an image, regenerate thumbnails, and change settings. WordPress checks the user’s permissions on every call.
